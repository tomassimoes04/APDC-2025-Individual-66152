Endpoints da API

A base da API é /rest. Todas as operações (exceto Registo/Login) requerem um token de autenticação no header Authorization: Bearer {tokenID}.

  • POST /rest/register/ : Registo de novo utilizador (OP1).
  • POST /rest/login/ : Login de utilizador (retorna AuthToken) (OP2).
  • POST /rest/login/logout : Logout (invalida token) (OP9).
  • POST /rest/user/changestate : Alterar estado da conta (ADMIN/BACKOFFICE) (OP4).
  • POST /rest/user/changerole : Alterar role da conta (ADMIN/BACKOFFICE) (OP3).
  • POST /rest/user/changepwd : Alterar a própria password (Utilizador autenticado) (OP8).
  • POST /rest/user/updateatts : Atualizar atributos do perfil (Permissões variáveis) (OP7).
  • POST /rest/user/listusers : Listar utilizadores (Visibilidade por role) (OP6).
  • DELETE /rest/user/{username} : Remover conta de utilizador (ADMIN/BACKOFFICE) (OP5).
  • POST /rest/worksheet/ : Criar/Atualizar folha de obra (BACKOFFICE/ADMIN) (OP10).
  • POST /rest/worksheet/updatestate : Atualizar estado de execução da obra (PARTNER associado) (OP10).

Consulte o README.md no repositório GitHub para mais detalhes sobre compilação e deploy.
